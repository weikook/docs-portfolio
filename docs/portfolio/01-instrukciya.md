# Пошаговая инструкция для корпоративной IT-системы

Пошаговая инструкция по выполнению операции в корпоративной IT-системе. *Кейс основан на реальном корпоративном проекте. Материалы обезличены и адаптированы для демонстрации.*

- **Задача пользователя:** согласовать проект с положительным решением.
- **Целевая аудитория:** владелец проекта.
- **Результат:** пользователь самостоятельно выполняет операцию в системе и может проверить ожидаемый рабочий сценарий системы.

## Согласование проекта: положительное решение `Go`.
!!! warning "Обратите внимание"
     У вас должна быть доступна задача на согласование во вкладке `Решения` карточки проекта.

### Шаги

#### 1. Откройте задачу на согласование

- Откройте карточку проекта и перейдите на вкладку `Решения`.
- Дважды щёлкните по задаче, которую необходимо согласовать (задача типа `Согласование проекта` с видом операции `Запуск инициативы`).
- Откроется форма `Согласование проекта`.

#### 2. Добавьте комментарий

- В правой панели формы `Согласование проекта` найдите поле `Комментарий к решению`.
- Введите комментарий. Поле необязательное, но рекомендуется оставить комментарий для уведомления коллег.

#### 3. Примите положительное решение

- Нажмите кнопку `Go`.

#### 4. Завершите согласование

- Нажмите `Провести и закрыть`. 

!!! note "Заявка согласована с положительным решением `Go`, форма закрыта, проект разморожен и готов к работе."

#### 5. Обновите проект

- Вернитесь в карточку проекта и нажмите `Ещё` → `Перечитать`.

> **На скриншотах выделено:** поле `Решение`, нужная задача, `Комментарий к решению`, кнопка `Go`, кнопка `Провести и закрыть`, кнопка `Ещё`, кнопка `Перечитать`.
