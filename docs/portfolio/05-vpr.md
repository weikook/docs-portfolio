# Как находить и объединять данные в Excel с помощью ВПР

*Разработано для корпоративной программы обучения пользователей.*

Когда данные лежат в большой таблице или на разных листах, ручной поиск неэффективен. Функция ВПР (VLOOKUP) автоматически находит нужную информацию по ключевому параметру и связывает таблицы между собой.

Рассмотрим два сценария:

- поиск конкретного значения внутри одной таблицы;
- перенос (подтягивание) данных из одной таблицы в другую.

## Сценарий 1. Поиск значения

Представим, что у вас есть база сотрудников и их размеров одежды. Задача — быстро узнать размер конкретного человека.

1. **Подготовьте ячейку для запроса.** В любой свободной ячейке напишите имя сотрудника так, как оно записано в таблице (например, «Мочалов, Дмитрий»).
2. **Начните формулу.** В соседней ячейке введите `=ВПР(`. Функция ищет значение в первом столбце таблицы и возвращает значение из нужного столбца справа.

    ```
    =ВПР(что_ищем; где_ищем; номер_столбца; точное_совпадение)
    ```

3. **Заполните аргументы по порядку:**
    - **Что ищем:** ячейка с именем, например `A2`.
    - **Где ищем:** выделите диапазон таблицы. Он обязательно должен начинаться со столбца с именами.
    - **Номер столбца:** из какого по счёту столбца диапазона брать данные. Если размер в четвёртом столбце, укажите `4`.
    - **Точное совпадение:** введите `ЛОЖЬ` или `0`, чтобы искать строгое совпадение, а не приблизительное.

Готовая формула:

```
=ВПР(A2;A:D;4;ЛОЖЬ)
```

Нажмите Enter. Функция найдёт человека и подтянет его размер.

## Сценарий 2. Перенос данных из другой таблицы

Часто данные лежат отдельно. Например, в основной таблице есть только имена, а размеры указаны в другом файле или на другом листе по итогам опроса.

1. **Подготовьте место.** Добавьте в основную таблицу новый пустой столбец, например «Размер».
2. **Начните формулу.** Встаньте в первую ячейку нового столбца и введите `=ВПР(`.
3. **Укажите ссылки.**
    - Первым аргументом выделите имя сотрудника в текущей строке.
    - Вторым, не закрывая формулу, перейдите на нужный лист и выделите диапазон, который начинается со столбца с именами и заканчивается столбцом с размерами.
    - Третьим укажите номер столбца с размером внутри диапазона. Если он второй, укажите `2`.
    - Четвёртым укажите `ЛОЖЬ` или `0`.

```
=ВПР(A2;Лист2!A:B;2;ЛОЖЬ)
```

!!! tip "Совет"
    Чтобы диапазон поиска не сдвигался при копировании вниз, закрепите его знаком доллара: `Лист2!$A:$B`. Затем растяните формулу вниз, и Excel подставит размеры для всех сотрудников.

## Что это даёт

- Находить позиции в больших базах за секунды.
- Сшивать данные из разных отчётов без ручного ввода.
- Автоматически проставлять цены, статусы или характеристики.
- Быстро и без ошибок приводить данные в порядок.
