# Как создать и настроить сводную таблицу в Excel

*Разработана для корпоративной программы обучения пользователей.*

Сводная таблица помогает обобщать и анализировать данные исходной таблицы. Например, с её помощью вы можете узнать, сколько часов отработал каждый сотрудник, сравнить показатели отделов или отфильтровать информацию за нужную дату.

## Подготовка исходных данных

Убедитесь, что условия создания сводной таблицы соблюдены.

**Шапка таблицы должна:**

- состоять из одной строки;
- содержать уникальные названия столбцов;
- не иметь пустых и объединённых ячеек.

**В области данных:**

- нет объединённых ячеек;
- нет полностью пустых строк и столбцов внутри диапазона. Отдельные пустые ячейки допустимы.

## Шаг 1. Преобразуйте диапазон в таблицу Excel

1. Выделите любую ячейку исходного диапазона.
2. На вкладке «Главная» нажмите `Форматировать как таблицу` и выберите стиль.
3. Подтвердите создание таблицы.

После этого появится вкладка `Конструктор таблиц`. В поле `Имя таблицы` можно задать собственное имя.

!!! warning "Важно"
    Имя должно быть без пробелов и начинаться с буквы (например, "Отчет"). Оно пригодится при настройке источника данных сводной таблицы.

## Шаг 2. Создайте сводную таблицу

1. Установите курсор в любую ячейку исходной таблицы.
2. Перейдите на вкладку `Вставка` и выберите `Сводная таблица` (в английской версии - PivotTable).
3. Проверьте, что источник данных указан верно.
4. Выберите, где разместить сводную таблицу (на новом или существующем листе), и нажмите `ОК`.

Excel откроет область сводной таблицы и список доступных полей.

## Шаг 3. Настройте структуру

В правой части окна находится список полей исходной таблицы, под ним - четыре области: **Фильтры**, **Столбцы**, **Строки**, **Значения**.

Чтобы построить сводную таблицу - перетащите нужные поля из списка в подходящие области.

!!! note "Пример"
    Допустим, в исходной таблице есть данные о стажёрах, отделах, датах и количестве часов стажировки. Чтобы узнать, сколько часов каждый стажёр провёл в компании, перетащите поле "ФИО" стажёра в область `Строки`, а "Часы стажировки" в область `Значения`. Excel автоматически рассчитает итоговое количество часов по каждому человеку.

## Шаг 4. Добавьте фильтр по дате

Чтобы анализировать данные за конкретный день, перетащите поле `Дата` в область `Фильтры`, а затем выберите нужную дату в появившемся фильтре. Сводная таблица покажет данные только за этот день. Например, можно посмотреть, сколько часов каждый стажёр отработал 4 или 14 февраля.

## Шаг 5. Добавьте группировку по отделам

Если нужно дополнительно сравнить показатели по отделам, перетащите поле `Отдел` в область `Столбцы`, оставив "ФИО" в строках и "Часы" в значениях. При необходимости можно продолжать использовать фильтр по дате. В результате вы получите таблицу, где видно, сколько часов каждый стажёр провёл в каждом отделе.

## Как обновить данные

Если исходные данные изменились, сводную таблицу нужно обновить. Как это сделать корректно?

- Если сводная таблица построена на основе обычного диапазона, убедитесь, что новые строки входят в этот диапазон.
- Если источник - таблица Excel (созданная на шаге 1), новые строки попадут в неё автоматически. Останется только обновить сводную таблицу.

### Чтобы обновить:

1. Щёлкните по сводной таблице.
2. Перейдите на вкладку `Анализ сводной таблицы`.
3. Нажмите «Обновить». 

!!! info "Если границы диапазона изменились, а таблица не ссылается на таблицу Excel, выберите `Изменить источник данных` и укажите актуальный диапазон."

## Частые вопросы

**Можно ли редактировать данные прямо в сводной таблице?**
Нет, сводная таблица предназначена только для анализа и автоматических расчётов. Если нужна обычная редактируемая копия:

1. Скопируйте сводную таблицу.
2. Вставьте её в нужное место, выбрав вариант `Вставить значения`.
После этого полученную таблицу можно изменять вручную.

**Что делать, если список полей исчез?**

1. Щёлкните по сводной таблице.
2. Откройте вкладку `Анализ сводной таблицы`.
3. Нажмите `Поля сводной таблицы` - панель снова появится.

!!! info "После настройки сводной таблицы вы сможете:"

    - получать итоговые показатели;
    - сравнивать данные по категориям;
    - фильтровать информацию по датам;
    - анализировать показатели по отделам и другим параметрам;
    - обновлять расчёты при изменении исходных данных.
