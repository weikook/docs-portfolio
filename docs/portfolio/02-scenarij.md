# Пользовательский сценарий и практическое задание

Последовательность действий пользователя и ожидаемое поведение системы. *Кейс основан на реальном корпоративном проекте. Материалы обезличены и адаптированы для демонстрации.*

- **Исходное состояние:** проект на этапе, когда нужно принять решение о его запуске.
- **Цель:** показать пользователю полный пользовательский сценарий положительного согласования проекта в системе от принятия решения до проверки результата в системе.
- **Целевая аудитория:** владелец проекта.

## Сценарий

Открыть проект → открыть вкладку `Решения` → открыть задачу согласования → принять решение `Go` → сохранить решение → обновить данные проекта → проверить статус и автоматически созданные документы.

## Практическое задание для владельца проекта

**Задача:** утвердите проект, запустите его в работу, проверьте автоматически созданные системой документы.

1. Откройте список проектов.
2. Откройте нужный проект.
3. Перейдите на вкладку `Решения` и откройте задачу согласования типа `Согласование проекта`.
4. Введите комментарий к решению.
5. Нажмите `Go`.
6. Нажмите `Провести и закрыть`.
7. Вернитесь в карточку проекта и обновите данные кнопкой `Перечитать`.
8. Проверьте статус проекта и автоматически созданные документы.

!!! note "Критерии успешного выполнения"
    Статус проекта изменился на `In progress`, система автоматически создала документы, необходимые для начала работ.
